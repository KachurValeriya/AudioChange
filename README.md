# Обработчик аудио

Программа для шумоподавления и изменения тембра аудио.

## Установка

1. Установите Python 3.13 или выше(обязательно поставьте галочку в PATH)
Далее команды выполняйте в терминале.

3. Создайте виртуальное окружение:
```
py -m venv venv
```
3. Активируйте виртуальное окружение:
```
venv\Scripts\activate
```

4. Установите зависимости:
```
pip install -r requirements.txt
```

### Запуск
```
py main.py
```
